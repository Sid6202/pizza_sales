 # Pizza Sales SQL Analysis Project
This is a SQL data analysis project based on a pizza sales dataset. 
The goal of this project is to practice SQL queries, improve business understanding, 
and analyze sales performance using real-world data.

## Question 1
```sql
1. Show all records from the orders table.

SELECT * 
FROM orders;
```
## Question 2

SELECT

    pizza_types;

## Question 11
```sql
11. Find total revenue generated from pizza sales.

SELECT 
    round(SUM(od.quantity * p.price),2)as Total_revenue
FROM
    order_details AS od
        JOIN
    pizzas AS p ON od.pizza_id = p.pizza_id
    ;
```
## Question 12
```sql
12. Find the average order value.

SELECT 
    ROUND(AVG(total_order_values), 2)
FROM
    (SELECT 
        ROUND(SUM(od.quantity * p.price), 2) AS total_order_values
    FROM
        pizzas AS p
    JOIN order_details AS od ON p.pizza_id = od.pizza_id
    GROUP BY od.order_id)
        AS avg_order_value;
```

## Question 14

14. Find the least ordered pizzas.

SELECT
    p.pizza_id, SUM(od.quantity) AS quantity

    pizzas AS p
        JOIN
    order_details AS od ON p.pizza_id = od.pizza_id

## Question 15
``` sql
15. Calculate total quantity sold for each pizza size.

SELECT 
    p.size, SUM(od.quantity) AS quantity
FROM
    pizzas AS p
        JOIN
    order_details AS od ON p.pizza_id = od.pizza_id
GROUP BY p.size
ORDER BY quantity DESC;

```
## Question 16
``` sql
16. Find revenue generated by each pizza category.

SELECT 
    pt.Category, ROUND(SUM(od.quantity * p.price), 2) AS Revenue
FROM
    order_details AS od
        LEFT JOIN
    pizzas AS p ON od.pizza_id = p.pizza_id
        LEFT JOIN
    pizza_types AS pt ON p.pizza_type_id = pt.pizza_type_id
GROUP BY pt.category
ORDER BY revenue DESC;

```
